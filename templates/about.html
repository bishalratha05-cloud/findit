ABOUT THE PROJECT

FindIt

A lightweight Information Retrieval System built for the Web Search Mining course.

⌕

Document indexing

Loads text from TXT, PDF and DOCX files into a searchable collection.

↗

BM25 ranking

Ranks documents using term frequency, inverse document frequency and document length normalization.

◷

Search history

Stores recent queries and result counts in a local SQLite database.

System workflow

Document collection → Text extraction → Tokenization and stop-word removal → BM25 scoring → Ranked search results.
